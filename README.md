# 페이체크

알바 근로계약서 사진이나 PDF를 올리면 최저임금, 수습 감액, 주휴수당, 휴게시간, 필수 기재사항(18세 미만이면 근로시간 제한까지)이 근로기준법·최저임금법에 맞는지 확인하고, 어려운 법 조항을 쉬운 말로 풀어 설명한 뒤 사장님께 보낼 정정 요청 문장까지 알려주는 모바일 웹입니다.

- 서비스: https://paycheck-pi.vercel.app
- 팀: 내돈내놔 (AI:ON 2026)
- 기획 문서: [`prd_v1.md`](prd_v1.md)
- 법적 근거: 판정에 쓰는 조항과 원문은 서비스의 [`/legal`](https://paycheck-pi.vercel.app/legal) 페이지에 있습니다 (출처: 국가법령정보센터). 데이터는 [`rules/legal-sources.ts`](rules/legal-sources.ts) 한 곳에서 관리합니다.

2026년 11월에 조사한 결과입니다. 조사한 범위에서는 알바 근로계약서를 점검해 주는 한국어 전용 서비스를 찾지 못했습니다.

페이체크만의 차별점:

1. **알바생이 사인하기 전에 쓰는 도구.** 작성 도구는 사장님용이고 양식은 빈칸이에요. 페이체크는 알바생이 이미 받은 계약서를 사진 한 장으로 점검합니다.
2. **알바 계약서에 맞춘 점검 항목.** 계약 연도별 최저시급과 다음 해 인상분, 수습 감액 조건(1년 이상 계약, 3개월 이내, 90%까지), 주 15시간 기준 주휴수당, 휴게시간, 필수 기재사항을 법 조문대로 확인합니다.
3. **판정은 AI가 아니라 규칙 코드.** 같은 계약서에는 항상 같은 결과가 나오고, 경계값은 테스트로 고정합니다. AI 설명에 코드가 계산하지 않은 숫자가 나오면 그 설명은 버립니다.
4. **모든 결과에 근거 조문 원문.** 결과마다 최저임금법·근로기준법 조문을 연결하고, 원문은 `/legal` 페이지에서 볼 수 있습니다.
5. **어려운 법 조항을 쉬운 말로.** "최저임금액 이상의 임금을 지급하여야 한다" 같은 조문을 "~해요" 체의 2~3문장으로 풀어, 왜 중요한지와 이제 무엇을 하면 되는지까지 설명합니다. 설명은 AI가 쓰지만 판정을 바꾸거나 더 세게 말할 수 없고, 숫자는 코드가 계산한 값만 쓰도록 검사합니다. AI 설명이 실패해도 사람이 미리 써 둔 쉬운 설명이 대신 나옵니다.
6. **다음 행동까지.** 문제가 있으면 사장님께 보낼 정중한 요청 문장을 바로 복사할 수 있습니다. 고용 관계를 해치지 않는 말투에 맞췄습니다.
7. **1350 상담 답변을 반영한 기준.** 애매한 기준은 고용노동부 고객상담센터에 직접 문의해 정했습니다 ([`prd_v1.md`](prd_v1.md) 부록 A).
8. **가입·저장 없음.** 회원가입이 없고 사진과 결과를 저장하지 않으며, 민감정보는 올리기 전에 직접 가립니다.

## 원칙: AI는 읽고 설명만, 판정과 계산은 코드

| 단계 | 누가 | 위치 |
| --- | --- | --- |
| 계약서 사진에서 항목 추출 | Claude (비전, 구조화 출력) | `lib/extract.ts`, `lib/contract-schema.ts` |
| 사용자가 추출값 확인·수정 | 사람 | `components/ConfirmScreen.tsx` |
| 법 기준 판정 (R1~R5, 18세 미만이면 R7) | TypeScript 순수 함수 + 단위 테스트 | `rules/` |
| 결과를 쉬운 말로 설명 | Claude (코드가 계산한 숫자만 쓰도록 검사) | `lib/explain.ts` |

같은 계약서에는 항상 같은 판정이 나오고, 판정 규칙은 `rules/rules.test.ts`의 경계값 테스트로 고정합니다.

## 개인정보

- 회원가입이 없고, 사진과 결과를 저장하지 않습니다.
- 주민등록번호·계좌번호는 사용자가 사진 앱에서 직접 가린 뒤 올립니다.
- 자세한 내용은 서비스의 `/privacy` 페이지를 참고하세요.

## 실행

```bash
npm install
cp .env.example .env.local   # 키를 채우거나 MOCK_AI=1로 키 없이 화면 개발
npm run dev                  # http://localhost:3000
npm test                     # 판정 규칙 테스트
npm run try-extract -- 샘플_근로계약서_하루커피.png   # 추출만 시험
```
